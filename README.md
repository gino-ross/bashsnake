# bashsnake

A classic Snake game written in pure Bash.

## Play

```sh
./snake.sh
```

Control the snake with the arrow keys. Scran fruit to increase your score.

- **r** — restart after game over
- **q** — quit

## Requirements

- Bash 3.2+ (shipped by default on mac & linux)
- A terminal with ANSI escape support (basically any modern terminal)
- `tput` (shipped by default on mac & linux)
- `perl` (macOS only, shipped by default)

## Platform compatibility

- **Linux** - fully supported
- **macOS** - fully supported
- **Windows** - works under WSL or Git Bash, but native CMD/PowerShell not supported
